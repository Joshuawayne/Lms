# Definition of done

- The agreed workflow and record visibility rules are implemented and documented.
- Validation, authorization, state changes and retry/concurrency behavior are explicit.
- Meaningful checks cover the rules and failures introduced by the change.
- Required lint, formatting, type, dependency, contract and test checks pass.
- Migration/contract/documentation changes accompany implementation changes.
- A reviewer can assess algorithm traceability, teacher workload and evidence integrity.
- Material limitations are documented; unfinished behavior is not presented as complete.

Local static analysis assists review. It does not prove architectural correctness,
security, educational effectiveness or complete authorization coverage.
