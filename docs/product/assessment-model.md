# Assessment model

Keep project performance, competency evidence and values observations separate.
Provide a combined progress overview without calculating a character score.

Practical assessment uses versioned rubrics with configurable criteria and scales,
teacher feedback and supporting photos, videos, code or documents. Group evidence
must preserve each learner's contribution and individual assessment where needed.

Values observations record activity/context, date, observed behaviour, evidence,
feedback and a next step. The eight values are love, responsibility, respect, unity,
peace, patriotism, social justice and integrity. Suggested LMS indicators are Jjenga
Code's own, not official KICD scoring descriptors. Distinguish not observed from a
low rating. Do not infer values from clicks, completion speed or assumed character.

Teacher reports are detailed; parent reports present appropriate released progress,
projects, attendance, feedback and goals. Preserve the rubric and report versions
used for historical results. Publish only through an authorized review workflow.
